# CSC 548 — Parallel Systems (NCSU)

Interactive HTML lecture decks (reveal.js) for **CSC 548: Parallel Systems**, Fall 2026.
The course is programming-focused (MPI · OpenMP · SIMD · CUDA · Big Data · Parallel I/O · Parallel Deep Learning).

## Decks
Open [`slides/index.html`](slides/index.html) for the landing page. Several advanced decks
(GPU sessions, Interconnection Networks, Tenstorrent) are reused and re-branded from the
companion course [CSC/ECE 506](https://github.com/fruitfly1026/CSC506).

In a deck: **S** speaker notes · **F** fullscreen · **ESC** overview · **→** reveal answers.
